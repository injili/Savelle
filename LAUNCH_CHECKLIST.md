## 5. Environment variables (Vercel → Project → Settings → Environment Variables)

| Variable | Required | Purpose |
|---|---|---|
| `NUXT_PUBLIC_SITE_URL` | **yes** | Production URL, no trailing slash (canonical, OG, sitemap, JSON-LD) |
| `NUXT_RESEND_API_KEY` | **yes** | Sends enquiry emails |
| `NUXT_ENQUIRY_TO_EMAIL` | **yes** | Inbox that receives enquiries |
| `NUXT_ENQUIRY_FROM_EMAIL` | **yes** | Sender on a domain **verified in Resend**, e.g. `Savelle website <website@yourdomain>` |
| `NUXT_UPSTASH_REDIS_REST_URL` / `NUXT_UPSTASH_REDIS_REST_TOKEN` | recommended | Shared rate limiting across Vercel functions (5 enquiries / 10 min / IP). Without them a per-instance in-memory limit applies |
| `NUXT_PUBLIC_SHOW_DRAFTS` | no | Force drafts on/off. Default: on for `nuxt dev` and Vercel **Preview** deployments, off for Production |

Notes:
- Use the `NUXT_` prefix exactly as written: Nuxt only maps prefixed variables onto runtime config.
- Without mail configured, production returns a friendly error on submit (HTTP 503) and logs the cause; in dev the email is printed to the console instead of being sent.
- The mail provider sits behind `server/utils/mailer.ts` (`Mailer` interface). To switch provider, implement it there.
- **Node version:** set Vercel's Node.js version to **22.x or later** (`package.json` → `engines`). Nuxt Content uses the native `node:sqlite` connector.

## 6. How to publish case studies and insights

### Case study
1. Clear the relevant gates (2 to 5 above).
2. Edit `content/work/<slug>.md`: correct the text, set `status` (`completed` / `proposed`), add `image` + `imageAlt` if permitted, and set `published: true`.
3. Redeploy. The card appears on the homepage (Featured Work) and `/our-work`; the detail page `/our-work/<slug>` is generated and added to `sitemap.xml`.

Rules enforced in code:
- Unpublished case studies are **excluded from production builds entirely** (`drafts.config.ts`), so their text never reaches the browser.
- Benin keeps `label: "Proposed engagement"` and the "Savelle's proposed contribution" heading while `status: proposed`. Don't change it until gate 5 confirms delivery.
- Smartel: the US$150,000 figure must stay framed as a fundraising ambition/target.
- Homepage Featured Work behaviour is set by `data/site.ts` → `featuredWork` (`'auto'` | `'intro-only'` | `'hidden'`).

### Insight article
1. Edit `content/insights/<slug>.md`: add `author`, `date` (ISO, e.g. `2027-02-14`), write the body in Markdown below the frontmatter, optionally `image`/`imageAlt`, then set `published: true`.
2. Redeploy. The card shows the date instead of "Forthcoming" and links to `/insights/<slug>` (article template with author, date, category, summary, body, related-service link and enquiry CTA).

> Forthcoming insights (title + summary) are intentionally public. Don't write draft article bodies into a `published: false` file on the production branch, because the body would ship in the client content bundle. Draft in a branch or a Vercel Preview deployment instead.

### Founder message
Set `data/site.ts` → `about.founder.founderName`; the attribution line then appears in production.
